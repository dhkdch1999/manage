# ⚔️ 팀파이트 감독

5v5 MOBA 자동 전투와 풋볼 매니저식 구단 운영을 합친 e스포츠 팀 매니지먼트 게임입니다.
신생팀 감독이 되어 2부 리그에서 시작해 승격 → 1부 우승 → 세계 대회 우승을 노립니다.

빌드 도구 없이 순수 HTML/CSS/JavaScript로 만들었기 때문에 GitHub Pages에 그대로 올리면 바로 플레이할 수 있습니다.

## 플레이 방법

- **온라인**: GitHub Pages를 켜면 `https://dhkdch1999.github.io/manage/` 에서 플레이
- **로컬**: `index.html`을 브라우저로 열기 (또는 `python3 -m http.server` 후 `localhost:8000`)

## 주요 기능

| 시스템 | 내용 |
|---|---|
| 포지션 | 탑·정글·미드·원딜·서폿. 선수마다 주 포지션, 선수단 화면에서 라인업 지정 (주 포지션이 아니면 -7%) |
| 선수 | 공격·방어·피지컬·운영·팀워크 (1~20), 숨은 잠재력·성장 속도·멘탈, 컨디션·피로·사기, 영웅별 숙련도 |
| 영웅 22종 | 영웅마다 갈 수 있는 포지션, 스킬+궁극기, 상성 (돌진형 ▶ 원거리형 ▶ 탱커형 ▶ 돌진형), 포지션에 안 맞는 영웅이면 -10% |
| 밴픽 | 2밴 → 스네이크 픽 1-2-2-2-2-1, 영웅을 고르면 맞는 포지션 선수에게 자동 배정, 선수 간 영웅 스왑, 포지션 슬롯 표시 |
| 3라인 맵 | 탑·미드·바텀 라인과 미니언 전선, 라인별 포탑 2개 + 넥서스, 정글 캠프 4개, 드래곤(영구 피해 강화)·바론(푸시 강화) |
| 경기 AI | 라인전 → 정글 갱킹·카운터 정글·미드 로밍·교전 합류 → 오브젝트 콜 → 5인 푸시. 레벨·CS 성장. 넥서스 파괴 또는 30분 운영 점수 판정 |
| 경기 화면 | 양옆 선수 카드(포지션·레벨·KDA·CS·현재 행동) + 중앙 맵 + 스코어보드(킬·포탑·드래곤·바론), 1x~8x/건너뛰기 |
| 팀 전술 | 공격적 / 균형 / 수비적 / **변칙적** (기습 갱킹·스플릿 푸시·페이크 후퇴, 간파 시스템), 하프타임 전술 변경 |
| 선수별 지시 | 집중 대상 (원딜·미드/체력 낮은 적/서폿 등), 교전 합류 타이밍 |
| 구단 운영 | 상금·스폰서·연봉, 훈련장·숙소 업그레이드, 팬 수 |
| 이적시장 | 자유계약, 다른 팀 선수 영입(오프시즌), 연봉 협상, 재계약, 방출, 판매, 스카우트("?" 능력치 공개) |
| 리그 | 1부·2부 각 8팀 더블 라운드로빈 → 상위 4팀 플레이오프, 승강제, 세계 대회 |
| 시즌 전환 | 나이·성장/하락·은퇴, 계약 만료, 신인 유입, 승률 기반 패치(버프/너프) |
| 저장 | localStorage 자동 저장 + JSON 내보내기/불러오기, 시드 기반 난수 |
| 티어리스트 | 밴픽 화면·영웅 도감에서 패치(시즌)별 S~D 티어 확인. 승률·픽률·밴률 + 패치 변경 반영, 표본이 적을 땐 시뮬레이션 예상 승률로 보정. 밴픽 카드에 현재 티어 배지 |
| 디버그 | 설정 화면에서 100판 자동 실행 → 영웅별 승률, 전술별 승률·점수차 편차 |

```

  data.js      모든 밸런스 수치(CONFIG), 영웅 데이터, 이름 풀, 시드 난수
  hero.js      영웅 스탯·상성·패치
  player.js    선수 생성·성장·가치·훈련
  tactics.js   팀 전술 보정, 변칙 플레이, AI 전술 선택, 간파 시스템
  battle.js    3라인 전투 시뮬레이션(로직) + 캔버스 렌더러 (분리되어 있어 렌더링 없이도 실행 가능)
  sim.js       밸런스 점검용 무작위 경기 (게임 내 디버그 + node 도구 공용)
  draft.js     밴픽 순서와 AI 밴픽
  league.js    게임 상태, 일정, 순위, 플레이오프, 주간 진행, 재정, 이적, 시즌 종료
  save.js      저장/불러오기
  ui.js        모든 화면
tools/
  sim-test.js     node tools/sim-test.js 800   → 무작위 전투로 영웅·전술 밸런스 확인
                  node tools/sim-test.js 120 42 balanced:defensive → 전술 맞대결
  one-game.js     node tools/one-game.js 7     → 한 경기를 20초 단위 타임라인으로 출력 (AI 행동 디버깅)
  season-test.js  node tools/season-test.js 3  → 여러 시즌을 자동 진행해 오류 확인
```

## 밸런스 조정

`js/data.js`의 `G.CONFIG`와 `G.HEROES`만 고치면 됩니다. 예:

- 변칙 전술이 너무 세다 → `CONFIG.TRICK.ambushDmg`, `splitObjBonus` 낮추기
- 간파가 너무 빠르다 → `CONFIG.TRICK.readPenaltyPerUse` 낮추기
- 경기가 너무 길다/짧다 → `CONFIG.MATCH_TIME`, `HALF_TIME`, 포탑 체력 `TOWER_HP`, `NEXUS_HP`
- 라인전이 너무 길다 → `CONFIG.LANING_END`, 라인 미는 속도 `PUSH_PER_UNIT`
- 드래곤·바론 가치 → `CONFIG.DRAGON`, `CONFIG.BARON`, 시간 판정 점수 `SCORE`
- 맵 모양·포탑·정글 위치 → `G.MAP`
- 티어 기준을 바꾸고 싶다 → `G.TIER` (등급 비율 `CUTS`, 픽·밴 가중치 `PRESENCE_W`, 예상치 비중 `PRIOR_GAMES`)
- 특정 영웅이 너무 세다 → 해당 영웅의 `hp`, `atk`, 스킬 `p`(위력) 조정

고친 뒤 `node tools/sim-test.js 800`으로 승률을 확인하세요. 영웅 승률은 대략 43~58%, 전술 4종은 47~55%, 변칙적은 점수차 편차가 가장 크게 나오도록 맞춰 두었습니다.

## 단순화한 부분

- 미니언은 개별 유닛이 아니라 라인별 "전선" 위치로 표현합니다 (전선이 적 포탑에 닿으면 포탑을 공격).
- 아이템·스펠·시야(와드)는 없습니다. 성장은 CS·레벨로만 표현합니다.
- v2(포지션 도입)부터 저장 형식이 바뀌어 이전 버전 저장은 불러오지 않습니다.

- 플레이오프와 세계 대회는 단판(Bo1)입니다.
- AI 팀은 시즌 중 이적을 하지 않고, 오프시즌에 자유계약 선수로 빈자리만 채웁니다.
- 다른 팀 선수 영입은 오프시즌에만 가능하고, 자유계약 선수는 언제든 영입할 수 있습니다.
